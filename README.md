Objective:
To design and deploy a complete data science project pipeline, from data preparation to model deployment via a Flask API, for predicting Iris flower species based on their features.

Project Highlights:

Dataset and Problem Overview:

Used the Iris dataset, a widely recognized dataset in data science, containing measurements of sepal length, sepal width, petal length, and petal width for classifying flowers into three species: Setosa, Versicolor, and Virginica.
Model Development:

Employed the Random Forest Classifier, a powerful ensemble algorithm for classification tasks.
Performed data preprocessing by splitting the dataset into training and testing sets.
Trained the model on the training data and evaluated its performance, achieving high accuracy on the test set.
API Development:

Created a RESTful API using Flask for seamless interaction with the predictive model.
Developed endpoints:
Home Endpoint (/): Displays a welcome message.
Prediction Endpoint (/predict): Accepts input features via a POST request in JSON format and returns the predicted flower species.
Testing and Deployment:

Hosted the Flask API locally for testing purposes.
Tested the API endpoints using tools like Postman and cURL, ensuring it handles requests and returns predictions correctly.
Key Achievements:

Successfully built a fully functional end-to-end pipeline in less than 500 lines of code.
Integrated machine learning with web development to deploy a predictive model as an API.
Demonstrated knowledge of Python, Flask, and RESTful API principles in the implementation.
This project serves as a foundation for future data science applications where models are deployed for real-world usage, emphasizing the importance of making machine learning models accessible through APIs.
